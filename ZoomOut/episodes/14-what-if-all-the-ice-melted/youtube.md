# 14 — What If All the Ice Melted?

## Title
What Would Earth Look Like If All the Ice Melted?

## Description
If every glacier and ice sheet on land melted, the sea would rise about 70 m (230 ft). In a simple flood-map model, much of Florida, Venice, Amsterdam and Shanghai would go under. But coastlines have been redrawn before, in the other direction.
